# KTH Neuro — full static website

All pages: Home, About, What We Do, Events, Projects, Partners, Connect, Join Us.

## Put it on GitHub Pages
1. Create a new GitHub repository.
2. Upload everything in this folder (keep the folder structure: index.html, the page folders, styles.css, fonts/, favicon.ico, .nojekyll) to the repo root.
3. Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. Live at https://<user>.github.io/<repo>/

Everything is self-contained; internal links work between pages.
